A digital product agency website built with a dark navy & vibrant orange aesthetic, tailored for **PROSPIRA OFFICE**.

> *"We Build Digital Products That Grow Businesses."*

## 🚀 Live Pages Included

The website is composed of **six distinct, fully responsive pages**:

1. [index.html](file:///c:/Users/ayode/Desktop/prospira%20office/index.html) — **Home** (Hero, 3D Dashboard Mockup, Mission Introduction, Statistics Benchmarks, Tech Marquee, Core Expertise Cards, Featured Work Showcase, CTA, and Footer)
2. [services.html](file:///c:/Users/ayode/Desktop/prospira%20office/services.html) — **Services** (Comprehensive deep dives into all 6 core services with mockups, capabilities, and business benefits)
3. [work.html](file:///c:/Users/ayode/Desktop/prospira%20office/work.html) — **Work & Case Studies** (Demonstration projects with category filtering and interactive modal case study inspector)
4. [process.html](file:///c:/Users/ayode/Desktop/prospira%20office/process.html) — **Process** (Interactive 5-stage timeline: Discovery, Strategy, Design, Development, Launch & Support)
5. [about.html](file:///c:/Users/ayode/Desktop/prospira%20office/about.html) — **About** (Core positioning statement, Mission, Vision, Values, and Approach to Innovation)
6. [contact.html](file:///c:/Users/ayode/Desktop/prospira%20office/contact.html) — **Contact** (Comprehensive project brief submission form, field validation, interactive service/budget pills, and instant modal confirmation)

---

## 🛠️ Features & Polish

- **Custom Abstract 'P' Logo**: Original SVG logo mark with dynamic ascending chevron cut and elegant typography (`Space Grotesk` + `Inter`).
- **Zero Heavy Dependencies**: Pure high-performance modern HTML5, CSS3 variables, and vanilla JavaScript ES modules.
- **Micro-Interactions**: Ambient radial glow, scroll reading progress bar, sticky glass header, responsive mobile drawer, and interactive modal dialogs.
- **No WhatsApp Buttons**: Fully compliant with strict corporate digital product agency requirements.
- **Vercel / Netlify Ready**: Includes `vercel.json` for clean URL routing (`/services`, `/work`, etc.).

## 💻 How to View & Run

Open any `.html` file directly in your web browser:
- Double-click `index.html` to open in your browser.
- Or run a local HTTP server:
  ```bash
  npx serve .
  # or
  python -m http.server 3000
  ```
